📘 How LIME Explained This Prediction?

LIME generates local explanations through a four-step process:

  1. Perturbing Input: LIME creates replica points by adding small random changes (perturbations) to the input measurements.
  2. Making Predictions: It runs these perturbed points through the production pipeline to get the model's confidence scores.
  3. Distance Weighting: It measures how close the perturbed points are to the original input. Points closer to the input are given higher weights.
  4. Fitting a Surrogate Model: It fits an interpretable linear model on these weighted points. The resulting linear coefficients represent the feature importances displayed below.

This process explains the local behavior around the prediction, showing why the model arrived at this specific choice.
